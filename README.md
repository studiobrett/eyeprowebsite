# EyePro Website

Website for EyePro optometry practices in Virginia and South Carolina.

## Locations
- Haymarket, VA
- Winchester, VA  
- Georgetown, SC

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Connected to Vercel for automatic deployments on push to main.

## Editing Content

All location data, services, and team info is stored in `/src/data/`. Edit those files to update site content.
